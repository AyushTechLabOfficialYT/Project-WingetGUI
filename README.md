# Project-WingetGUI
An attempt to give winget a GUI

Hello there this is just a HTML file with the extension .hta to make it open as a native app and work properly.
This app is just a way to use the winget command to update apps in windows but with a GUI based interface.

I made this by giving AI a 2000 characters long prompt and 2 MS paint made image templates.

HOW TO USE-
Just run the WingetGUI.hta file and the interface will automatically scan and list the app whose updates are available.
Just click the UPDATE button to update them.
Clicking UPDATE ALL will open up a dialogue so you can deselect any apps you don't want to update and click the update button.
Meanwhile, in the menu (3-Dashed) you can change the theme (Default: Dark), toggle Auto Shutdown(Untested option, GOOD LUCK using that) and block apps (you don't the app to be on the update list E.g. Edge)
